# Contributing to Scriptman

Thank you for your interest in contributing to Scriptman!

## How to Contribute

1. **Fork the repository**  
   Click the "Fork" button at the top right of the GitHub page to create your own copy.

2. **Clone your fork**  
   ```bash
   git clone https://github.com/Gabriel-Dakinah-Vincent/Bash-exercises.git
   cd Bash-exercises
   ```

3. **Create a new branch**  
   ```bash
   git checkout -b your-feature-branch
   ```

4. **Make your changes**  
   Edit or add files as needed. Please follow the existing code style and conventions.

5. **Test your changes**  
   Ensure your changes work as expected and do not break existing functionality.

6. **Commit your changes**  
   ```bash
   git add .
   git commit -m "Describe your changes"
   ```

7. **Push to your fork**  
   ```bash
   git push origin your-feature-branch
   ```

8. **Open a pull request**  
   Go to the original repository and click "Compare & pull request". Provide a clear description of your changes and reference any related issues.

## Guidelines

- Document any new features or changes in the `README.md`.
- Reference issue numbers in your pull request if you are fixing a bug.
- For major changes, please open an issue first to discuss your proposal.

## Support

If you have questions or need help, please open an issue or join the Discussions tab.
